# 테스트 스타일 (web/, Vitest)

- 테스트는 `web/tests/`에 둔다 (FS 10장). 파일 이름은 대상 파일 이름에 `.test.ts`를 붙인다. 예: `lib/format.ts` → `tests/format.test.ts`
- **순수 함수**(`lib/`의 계산·판정·포맷)만 단위 테스트한다. 컴포넌트와 화면은 수용 기준 수동 확인으로 한다 (FS 방침).
- 테스트 이름은 **한국어**로 "무엇을 넣으면 무엇이 나온다" 형태로 쓴다. 예: `it('자본총계가 0이면 부채비율은 null이다')`
- 이 프로젝트에서 틀리기 쉬운 경계값(눈금 끝, `0`, `null`(데이터 없음), 적자)은 반드시 케이스에 넣는다.
- 테스트에서 실제 DB·외부 API를 호출하지 않는다.
