# CORE — 재무 레이더 핵심 기능 요약

> **기준: `docs/PRD.md`·`docs/FS.md` 2026-11-20.** 규칙·문구·수용 기준은 PRD, 구현 방식은 FS가 기준이다. 기능 1개당 최대 3줄.

**한 줄 정의:** 초보 개인투자자가 종목을 검색하면 최근 3개년 실적과 재무 변화를 쉽게 보여주고, 재무 조건으로 종목을 걸러볼 수 있는 웹앱 (비영리 과제).

**원칙:** 매수·매도 추천·평가 표현·신호등 없음. 회사가 공시한 숫자만 쓰고, 판단은 사용자에게 맡긴다.

**개발 순서 (PRD 2-1):** MVP F-01 → F-02 → F-05 → F-03 → F-07 / 2차 F-08 → F-09 → F-14 → F-17 → F-18 → F-15 → F-16 → F-10 / 확장 F-11 → F-12 → F-13

---

## MVP

**F-01 종목 검색**
- 종목코드(숫자면 앞부분 일치)·종목명(대소문자·띄어쓰기 무시)으로 찾고, 연관검색어 최대 10개를 보여준다.
- 우선주·스팩·코넥스는 제외, 외국회사는 `지원하지 않음` 표시. 키보드만으로 선택 가능.

**F-02 최근 3개년 실적 그래프**
- 매출액·영업이익·순이익을 항목별 막대그래프 3개로 나란히 그린다 (Recharts, 적자는 0 아래 막대).
- 연결/별도 기준과 사업연도를 표시하고, 금융회사는 영업이익·순이익 2개만 보여준다.

**F-05 재무 리포트카드**
- 부채비율·영업이익률·매출 증가율 3개를 고정 눈금 위 위치(점) + 3년 방향 화살표로 보여준다 (좋고 나쁨 판정 없음).
- 배치가 판정한 "눈여겨볼 변화" 문장 8종 중 앞 3개를 보여주고, 자본잠식(완전·부분)은 안내로 표시한다.

**F-03 필터 문구 목록**
- 초보자용 문구와 계산 조건을 짝지은 필터 20개를 묶음 6개(매출·이익·이익률·빚·자산과 자본·배당)로 정의한다.
- 판정은 배치가 하고(`matched_filters`), 웹앱은 문구·툴팁·부딪히는 짝 10쌍·근거 값 열을 상수로 가진다.

**F-07 스크리너 (필터 검색 실행)**
- 필터를 최대 3개 골라 모두 맞는(AND) 회사 목록을 시가총액·근거 값 열과 함께 보여준다.
- 기본 정렬은 가나다순(순위처럼 보이지 않게), 부딪히는 필터는 흐리게, 상태는 URL에 담아 뒤로 와도 유지.

## 2차

**F-08 업종 비교**
- 리포트카드 눈금에 같은 업종(KSIC 중분류) 가운데 값(중앙값)을 함께 찍고 "높아/낮아/같아"로만 비교한다 (회사 3개 미만이면 숨김).
- "같은 업종 회사 보기" 지표 비교 목록은 정렬·페이지를 URL 쿼리 링크로 서버가 다시 그린다 (API Route 없음, null 값은 맨 뒤).

**F-09 주가 수준 (PER·PBR)**
- 보통주 시가총액 기준 PER(0~50배)·PBR(0~5배)을 눈금 + 업종 가운데 값으로 보여준다 (싸다·비싸다 판정 없음).
- 적자·자본 0 이하는 계산하지 않는다는 안내, 주가 기준일과 재무 기준 연도를 함께 표시한다.

**F-14 배당 정보**
- 보통주 주당 배당금·배당수익률 3년을 표로 보여주는 카드 (항상 표시).
- 배당수익률은 공시 값만 쓰고 직접 계산하지 않으며, 무배당·공시 없음·데이터 없음을 구분해 표시한다.

**F-17 최근 공시**
- 종목 화면 맨 아래(기사 칸 오른쪽)에 지분공시를 뺀 최신 공시 5개를 `제목 · 제출인 · 날짜`로 보여주고 DART 원문을 새 탭으로 연다.
- DART `list.json`을 서버에서 불러 1시간 캐시, DB 저장 없음. 실패해도 공시 칸에만 실패 문구.

**F-18 경제 기사**
- 첫 화면 경제 기사 5개 + `/news`(상단 메뉴 없음), 종목 화면 회사 기사 5개를 네이버 검색 API 뉴스(NAVER API HUB)로 보여준다.
- 결과를 가공·저장·AI 입력하지 않고(약관), `제목 · 도메인 · 시각` + 원문 링크 + 네이버 표시만. 캐시 30분/1시간, 짧은 종목명은 네이버 링크로 대신한다.

**F-15 업종으로 둘러보기**
- 대분류(HTML `<details>`로 펼침) → 중분류(분류 번호순, 회사 수) → 회사 목록 순으로 회사 이름을 몰라도 찾게 한다.
- 대표·인기 종목은 없고, 회사 목록은 가나다순/시가총액순을 URL 쿼리 링크로 다시 그린다 (F-08과 같은 방식).

**F-16 처음 읽는 순서 안내**
- 종목 화면에서 driver.js 투어로 매출 → 이익 → 부채비율 → PER·PBR → 배당 순(일반 5단계, 금융회사 3단계)으로 짚어 준다.
- 기사·공시 칸은 투어에 넣지 않는다 (2026-11-20). 첫 방문 알림 띠 + "읽는 순서" 버튼, 본 여부는 `localStorage` 값 하나로 기억한다.

**F-10 조건 찾기 챗봇**
- 스크리너 맨 위에서 문장을 입력하면 AI(OpenRouter 무료 모델)가 필터 ID·미지원 조건 코드만 JSON으로 고르고, 문구는 모두 고정 문구다.
- 무료 한도 보호: 정규화한 같은 문장은 1일 캐시, 하루 AI 호출은 상한 40회 (넘으면 "지금은 쓸 수 없어" 문구). 기사 데이터는 AI에 넣지 않는다.

## 확장

**F-11 로그인**
- Supabase Auth 이메일 매직링크 (Gmail SMTP), 비밀번호 저장 없음, 이메일 주소만 수집한다.
- `user_settings` 행은 `auth.users` insert 트리거가 만든다. 로그인 뒤 원래 화면으로 돌아오고(사이트 안 경로만 허용), 탈퇴하면 추적 종목·알림이 함께 지워진다.

**F-12 추적 종목·마이페이지**
- 종목 화면 "추적하기"로 1인 최대 20개 종목을 등록한다. 로그인 전에 누르면 매직링크 주소의 `?watch=`로 로그인 뒤 자동 등록된다.
- 마이페이지에 추적 종목 카드(작은 실적 막대 + 변화 문장 1개), 웹 알림 목록, 이메일 수신 설정, 계정 관리를 둔다.

**F-13 추적 종목 알림**
- 새 실적·감사의견 변경은 DART 월 배치가, 목록에서 빠짐은 KRX 일 배치가 웹 알림으로 만든다 (같은 변화는 한 번만).
- 이메일 수신을 켠 사용자에게는 매일 워크플로의 `batch/notify_mail.py`가 하루치를 한 통으로 묶어 보낸다. 수신 거부는 확인 화면 + 버튼(POST)으로만 꺼진다.
